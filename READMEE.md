## 🎮 play tic-tac-toe against my repo

GitHub strips JavaScript from READMEs, so instead of faking a game, I built one that's actually driven by GitHub itself: every visitor can play a real move, a bot replies, and the board below is a live SVG that gets repainted by a GitHub Action after every move.

**How to play:** open a new [issue](../../issues/new?title=move+5) titled `move N` where N is 1–9 (numbers correspond to the grid below). A bot will play back instantly, comment the result, and close the issue. The board updates itself right here.
